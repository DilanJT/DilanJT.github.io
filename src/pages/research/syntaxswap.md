Developed an NLP-based code translation application using **GraphCodeBERT** with relative positional encoding attention mechanism to convert Java source code to equivalent JavaScript. The system demonstrates advanced understanding of programming language semantics and syntax transformation.

**Key Technologies:** PyTorch, Flask, React, GraphCodeBERT, Transformer Architecture
